Capa Web
REST Controllers que reciben las peticiones del FE. Validan, delegan, no contienen lógica de negocio.
Aplicación
Servicios de orquestación. El ExpedienteService es el corazón: lanza las 3 búsquedas paralelas.
Dominio
Entidades JPA, repositorios por BD y el Unifier que fusiona los resultados de las 3 fuentes.
Infraestructura
CredentialResolver, DataSourceFactory y Registry. Aquí ocurre la magia del cache y resolución dinámica.
Cache de conexiones
Mantiene los 3 DataSources Hikari activos en memoria. Se refresca on-demand al fallar.

Estrategia de cache
Lazy load + invalidación on-failure. Las credenciales NUNCA expiran por tiempo, solo cuando una conexión falla.
Reintento controlado
Solo un reintento por request. Si falla dos veces, se devuelve resultado parcial y se registra en bitácora.
API interno del OJ
Solo se invoca en arranque y cuando una credencial deja de funcionar. Bajo tráfico hacia él.
