Secuencia técnica

Autenticación e inicialización

SECUENCIA 
sequenceDiagram
    actor U as Usuario
    participant L as LoginPage
    participant F as AuthFacade
    participant S as AuthService
    participant I as AuthInterceptor
    participant API as Backend
    participant R as Router
    participant SH as Shell

    U->>L: Ingresa credenciales
    L->>F: login(usuario, clave)
    F->>S: authenticate(creds)
    S->>API: POST /auth/login
    API-->>S: { token JWT, user, role }
    S->>S: localStorage.setItem('token')
    S-->>F: Signal<User>
    F-->>L: estado autenticado

    Note over L,R: Redirección post-login

    L->>R: navigate('/busqueda')
    R->>R: AuthGuard.canActivate()
    R->>R: RoleGuard.canActivate()
    R-->>SH: cargar Shell + ruta hija

    SH->>F: getCurrentUser()
    F-->>SH: { nombre, rol, despacho }
    SH-->>U: render UI con permisos

    Note over U,API: Requests siguientes con token

    U->>SH: acción cualquiera
    SH->>API: HTTP request
    I->>I: añadir Bearer token
    API-->>SH: respuesta
