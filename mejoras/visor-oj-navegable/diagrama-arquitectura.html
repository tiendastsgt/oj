Presentación
Componentes Angular standalone organizados por feature. Páginas y vistas de cada módulo.
Aplicación
Router con guards de auth y rol, signals de estado y facades que orquestan dominio.
Dominio
Servicios de negocio puros y modelos/DTOs. Sin conocimiento de HTTP ni UI.
Infraestructura
HttpClient, interceptores de auth/error/loading, localStorage y conexión al backend.
Shared
Librería de componentes UI, pipes, utils y los design tokens del sistema visual.

sequenceDiagram
    actor Usuario as Asesor
    participant UI as FileListComponent
    participant Facade as AncladosFacade
    participant Service as AncladosService
    participant HTTP as HttpClient
    participant LS as localStorage
    participant API as Backend Java

    Usuario->>UI: click en pin
    activate UI
    UI->>Facade: toggleAnclado(expNum, docId)
    activate Facade

    Facade->>Service: toggle(expNum, doc)
    activate Service

    Note over Service,LS: Optimistic update local
    Service->>LS: get / set anclados
    LS-->>Service: estado actualizado

    Service->>HTTP: POST /api/anclados
    activate HTTP
    HTTP->>API: HTTP request + JWT
    activate API
    API-->>HTTP: 200 OK
    deactivate API
    HTTP-->>Service: Observable de Anclado
    deactivate HTTP

    Service-->>Facade: Signal de AncladosState
    deactivate Service

    Facade-->>UI: render reactivo
    deactivate Facade

    UI-->>Usuario: pin dorado + contador actualizado
    deactivate UI

    Note over UI,API: Si el HTTP falla, se hace rollback del estado local
