Recovery

Refresh on-failure del cache

SECUENCIA 
sequenceDiagram
    participant Repo as Repository
    participant Cache as ConnectionCache
    participant Resolver as CredentialResolver
    participant API as InternalApiClient
    participant Internal as API Interno OJ
    participant Factory as DataSourceFactory
    participant Oracle as Oracle DB

    Repo->>Cache: getDataSource(ADOLES_EN_CONFLICTO)
    Cache-->>Repo: HikariDataSource

    Repo->>Oracle: SELECT ...
    Oracle--xRepo: ORA-01017 invalid credentials

    Note over Repo,Resolver: Detecta error de credencial

    Repo->>Resolver: refreshCredentials(ADOLES_EN_CONFLICTO)

    Resolver->>Cache: invalidate(ADOLES_EN_CONFLICTO)
    Cache->>Cache: cierra pool antiguo
    Cache-->>Resolver: ok

    Resolver->>API: fetchCredentials(ADOLES_EN_CONFLICTO)
    API->>Internal: GET /credentials/ADOLES_EN_CONFLICTO
    Internal-->>API: 200 OK con nueva credencial
    API-->>Resolver: CredentialDto

    Resolver->>Factory: build(credentialDto)
    Factory->>Factory: crea HikariDataSource nuevo
    Factory-->>Resolver: DataSource listo

    Resolver->>Cache: store(ADOLES_EN_CONFLICTO, ds)
    Cache-->>Resolver: ok

    Resolver-->>Repo: nuevo DataSource

    Repo->>Oracle: SELECT ... reintentando
    Oracle-->>Repo: resultados OK

    Note over Repo,Oracle: Si vuelve a fallar, se marca como degradado
y se incluye en _meta.partialResults

Descarga de archivo binario

STREAMING + RANGE 
sequenceDiagram
    participant FE as Frontend
    participant Filter as JwtAuthFilter
    participant Ctrl as ArchivoController
    participant Svc as ArchivoService
    participant Resolver as CredentialResolver
    participant Repo as ArchivoRepository
    participant DS as DataSource
    participant Oracle as Oracle DB
    participant Audit as AuditAspect

    FE->>Filter: GET /archivos/abc123/contenido
Range: bytes=0-1048575
    Filter->>Filter: valida JWT y permisos
    Filter->>Ctrl: continúa

    Ctrl->>Svc: streamArchivo(id, rangeHeader)

    Svc->>Repo: findById(id)
    Repo->>Resolver: getDataSource(fuente)
    Resolver-->>Repo: DataSource del cache
    Repo->>DS: abre conexión
    DS->>Oracle: SELECT metadata + lob_locator
    Oracle-->>DS: archivo encontrado
    DS-->>Repo: ArchivoEntity con BLOB stream
    Repo-->>Svc: entity

    Note over Svc,Ctrl: Soporta Range requests
para video y audio

    Svc->>Svc: calcula offset y longitud
    Svc->>Oracle: lee bytes solicitados desde BLOB

    Svc-->>Ctrl: ResponseEntity con InputStream
    Ctrl->>Audit: registra descarga
    Audit-->>Ctrl: ok asíncrono
    Ctrl-->>FE: 206 Partial Content
Content-Range bytes 0-1048575

    Note over FE,Oracle: El navegador continúa pidiendo
rangos para reproducir video

State machine

Ciclo de vida de una entrada del cache

STATE MACHINE 
stateDiagram-v2
    direction LR

    [*] --> NoCargado: Estado inicial
al arrancar el API

    NoCargado --> Cargando: Primera petición
llama al API interno

    Cargando --> Activo: Credenciales obtenidas
HikariCP iniciado

    Cargando --> Fallido: API interno no responde
o credencial inválida

    Activo --> Activo: Queries exitosas
uso normal

    Activo --> Invalidado: Query falla con
error de credenciales

    Invalidado --> Cargando: Refresh on-demand
se reintenta

    Activo --> Cerrado: Admin invalida
vía endpoint

    Cerrado --> Cargando: Próxima petición
fuerza refresh

    Fallido --> Cargando: Reintento automático
en próxima petición

    Activo --> [*]: Shutdown del API
    Fallido --> [*]: Shutdown del API
